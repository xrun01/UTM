# 回译代理说明

主代理把下面的说明发给回译代理，填入 `{lang}`、`{in}`、`{out}` 这 3 个参数。回译代理必须是新代理，不能是改稿代理。

---

你把一组 `{lang}` 文本直译成英文。这些文本来自一个 Mac 虚拟机 App 的界面。

## 不要做

- 只读 `{in}` 这 1 个文件。不要读仓库里的其他文件，尤其是 `Platform/**/*.xcstrings` 和 `i18n/`。理由：你的回译用来检查译文本身表达了什么，看到英文原文就失去了检查作用。
- 不要润色，不要猜作者想说什么。按字面直译。读者按字面理解成什么，你就译成什么。
- 不要补全省略的主语或宾语。
- 占位符（`%@`、`%lld`、`%1$@`）原样保留。

## 输入

`{in}` 是 JSON 数组，每项是 `{ "id": "…", "text": "…" }`。用 Read 工具读它，用 Write 工具写 `{out}`。

## 输出

把结果写成 JSON 文件 `{out}`：

```json
[
  { "id": "…", "back": "直译的英文", "note": "" }
]
```

- 原文有歧义、读不通或有语法错误时，在 `note` 里用 1 句简体中文写出来。没有就写空字符串。
- 每个输入项都必须有 1 个输出项，`id` 不变。

写完后，用 `bun -e` 读一次 `{out}`，确认 JSON 能解析、条数和输入相同。最后回复 1 句话：总条数和写了 `note` 的条数。
